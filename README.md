# Re-route

채용 → 프론트엔드 → 다음 이야기. 커리어와 개인 프로젝트를 날짜순으로 정리한 개인 사이트입니다.
React + TypeScript + Vite, GitHub Pages 배포.

```bash
npm install
npm run dev            # 개발 서버
npm run build          # 타입 체크 + 빌드
npm run check:privacy  # 개인정보 검사 (.privacy-terms 에 금칙어를 한 줄씩 적어 두세요, git 제외)
```

- 행보 추가: `docs/ADD_ENTRY.md`
- 다른 레포 조사: `docs/PROJECTS.md`
- 에이전트 지침: `CLAUDE.md`
